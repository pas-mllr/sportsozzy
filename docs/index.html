SportsOzzy 🎙️

Replace dry, boring sports commentary with a live AI commentator — half Aussie larrikin, half weary stand-up — while keeping the stadium sound.

This static site plays streams straight from their CDN, so it needs the direct .m3u8 URL. Find it on the stream's page via your browser's dev tools: F12 → Network tab → filter m3u8 → copy the URL.

Stored only in this browser (localStorage). Commentary and speech requests go directly from your browser to OpenAI — no server in between.

How it works

  1. Your browser plays the HLS stream and snapshots frames from it every few seconds.
  2. The frames go to an OpenAI vision model that writes the next commentary line in character.
  3. The line is spoken by OpenAI's gpt-4o-mini-tts speech model with a rowdy commentator delivery.
  4. The original commentator's voice is cancelled out of the broadcast audio (centre-channel removal), so crowd and ambient sound stay — with automatic ducking while Ozzy talks.

Limitations of this static version: the stream's CDN must allow cross-origin access (most do), geo-blocked streams need you to be in the right country, and DRM streams can't be played at all. The self-hosted server version adds a stream proxy and URL auto-detection for the tricky cases.

For personal use with streams you're allowed to watch. Nothing is re-broadcast; the stream plays in your own browser.
